# Mobile Sales Dashboard - PowerBI

## Project Overview
Power BI dashboard analyzing 769M in mobile sales from 4K transactions. Identified top brands, cities, payment trends, and customer ratings.

## Key Metrics
- *Total Sales*: 769M
- *Total Quantity*: 19K
- *Total Transactions*: 4K  
- *Average Price Per Unit*: 40K

## Key Insights
- Top City: Delhi leads in total sales
- Top Brands: Apple, Samsung, OnePlus have highest sales
- Payment Trend: UPI is most used with 1.0K transactions
- Customer Satisfaction: 1.5K customers gave 5-star ratings
- Seasonality: Sales peak in July and December

## Tools & Skills
Power BI, DAX, Data Visualization, KPI Dashboard, Business Analysis
